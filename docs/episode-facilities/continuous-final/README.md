# 최종 프로덕션 3D 연속 검증

2026-10-25. 시설 개선 후 남았던 새 게임→엔딩 무주입 연속 검증을 완료했다. 게임 코드·비주얼·진행 조건은 변경하지 않았다. 이전 체크포인트 분기 검사는 반복하지 않았다.

## 실행과 무주입 기준

```sh
npm run build:playtest
PRODUCTION_CHECK=1 FIRST_PERSON_CHECK=episode EPISODE_ARTIFACTS=docs/episode-facilities/continuous-final node scripts/verify-browser.mjs
```

TypeScript·프로덕션 빌드·정적 배포 감사를 통과한 동일 `dist/`를 Vite preview로 제공했다. [빌드 파일·크기·SHA-256](build.json)을 남겼다. 검증 중 앱 소스나 빌드를 변경하지 않았다. Spring과 외부 AI는 사용하지 않았다. 기존 Three.js 청크 765.75 kB 경고는 유지했다.

새 임시 Chrome 프로필의 새 게임에서 시작했다. 플레이 중 localStorage에 상태를 쓰거나 초기/완료 상태를 주입하지 않았고, reducer 직접 호출·위치 순간이동·챕터 점프를 사용하지 않았다. 경로 계산은 게임의 월드/저장 정보를 **읽기만** 하며, 실제 이동과 시점은 CDP WASD·마우스, 조사는 E, 메뉴·선택·퍼즐은 기존 DOM UI 이벤트로 처리했다. 자동 이어하기도 게임의 기존 버튼을 사용한다. `checkpoints.json`은 해당 시점의 실제 저장을 **출력한 기록**이며 이번 실행의 입력으로 다시 주입하지 않았다.

1280×1000 헤드리스 Chrome, 로컬 데스크톱 환경이다. 실제 모바일/GPU 성능·사람의 판단 시간 검사가 아니다.

## 저장·입력·시설 확인

- 대합실, 계단, 열차 탑승 전/후, 문래역, 등록 처리 후, 정비 통로, 대피소 도착, 엔딩에서 실제 앱이 만든 저장을 새로고침해 이어 갔다. 구역·진행·자원·소지품·단서·메시지가 동일하며 유효한 3D 위치/yaw/pitch도 정확히 복원됐다.
- 최종 결과는 체력 **80**, 배터리 **51**, 단서 **30개**, 소지품 **절연 장갑·전기실 열쇠**, NPC 동행이다. 결과의 자원·단서·메시지가 실제 진행 기록과 일치했다. 엔딩 후 이어하기·결과 재열람·도착 확인대 재조사로 결과가 다시 생성되거나 변하지 않았다.
- 개선된 안내도·계기·물품함·비상 부스·호출기·승인기·휴대폰·통신 랙·정차 패널·감지기·등록 단말·경로 제어반·도착 확인대를 정상 동선에서 식별하고 조준해 사용했다. E 실행 직전에 실제 3D HUD가 활성화됐는지 검사했으며, 조사·장치 조작·기존 퍼즐 결과가 다음 진행에 연결됐다. 벽·닫힌 문 너머의 잘못된 선택이나 조작으로 진행하는 현상은 관찰되지 않았다.
- 거리 밖·뒷면·벽 가림의 별도 거부 검사(허용되지 않아야 하는 조작)는 이번 연속 경로와 구분한다. 해당 대표 15개/시설 단위 검사는 [시설 개선 기록](../README.md)의 통과 결과를 유지하며 이번에는 체크포인트를 주입해 반복하지 않았다.
- 모든 기록 시점에 3D Canvas 1개, 로딩 오류/2D 대체 진입 없음. 전기실 왕복 전후 입력 리스너도 `keydown=2`, `keyup=2`, `mousemove=1`, `blur=5`로 동일했다. 다른 구역에서도 같은 수치다. 탐색/대화/퍼즐 종료와 재접속 후 탐색을 계속했다.

## 오류와 변경 범위

이번 완주에서 **진행을 막는 새 게임 오류는 발견되지 않았다**. 이전 자동 경로의 조준·현장 조작 대기 보완이 적용된 상태에서 첫 시도에 완주했으며 게임 코드·시설 외형·판정·오디오·설정 변경은 하지 않았다. 문서와 검증 산출물만 갱신했다.

[프로덕션 요청/콘솔 기록](production-network.json): 런타임 예외 0건, 콘솔 오류 0건, 에셋 실패 0건, AI/API 요청 0회, 외부 요청 0회. 직접 URL 재접속과 로컬 정적 에셋 바이트 검사도 통과했다.

완료 확인대의 보조 기둥에 일부 각도에서 작은 표면 잔무늬가 보였다([완료 화면](10-complete.png)). 진행과 조작에는 영향이 없었으며 원인 분리는 이번 범위에 포함하지 않았다. 요청대로 비주얼 수정 없이 관찰 사항으로 남긴다.
