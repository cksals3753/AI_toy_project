# 챕터 2 재구성 제안 — 승인 전 설계 기록

이 문서는 B 승인 전의 설계안이다. 아래의 현재/미구현 표현은 제안 당시 기준이다. 2026-10-25 사용자 승인 후 구현했으며, 확정 좌표·안전 전환 조건·실행 결과는 [구현 기록](chapter2-restructure/README.md)을 따른다.

당시 A 작업의 범위: 이번 A 작업에서는 침수 판정·맵·감염자 행동·스토리·저장 필드를 변경하지 않는다. 구현 승인과 별개로 검토할 문서이며, 현재 완성된 기능으로 안내하지 않는다.

## 현재 코드에서 확인한 기준

- `world.ts`: 대합실은 기존 960×600 월드의 벤치 두 개·기둥 두 개와 안내도/점검창/데스크/개찰구, 왼쪽 직원 통로, 아래 전기실로 구성된다. `chapter2Scene.ts`에는 개찰구·승강장 계단·직원/전기실 방향 표식과 비상 조명이 이미 있다. 이를 새로 만든 기능처럼 제안하지 않는다.
- `chapter2.ts` / `chat/chapter2Public.ts`: 직원 통로의 설비 표시등·누전·자동 폐쇄, 개찰구 예비 전원과 최대 두 회로가 기존 사실이다. 침수는 첫 방과 점검창의 기록에는 있지만 대합실의 단계별 통행 가능 영역을 바꾸지는 않는다.
- `threat.ts` / `useThreat.ts`: 감염자 한 명, 충돌과 같은 기준의 길찾기, 시야 차단·마지막 목격 위치·수색·소리 조사, 전기실 분리 안전 구역과 체크포인트가 구현돼 있다. 메뉴/대화/퍼즐/포커스 이탈/복귀 대기에는 정지한다. 바닥 표식 자체는 안전 구역이 아니다.
- `comfort.ts`: 감도·세로 FOV·이동 배율이 있다. 밝기 설정은 없다. 이번 제안은 멀미 완화 설정과 정지 규칙을 유지한다.

## 공간 구성: 공용 대합실 → 직원 설비 구역 → 승강장

맵 크기를 늘리지 않는다. 기존 상단 벽을 역 안내·매표/안내 데스크 벽면으로, 오른쪽 개찰구를 통행 경계로 강조한다. 개찰구 너머의 승강장 계단은 표식과 난간으로 미리 보인다. 환승 표식에는 침수로 폐쇄된 방향과 유효한 우회 방향을 함께 표시한다. 안내 데스크의 직원 인수인계 메모가 E-01 전기실 열쇠의 필요성을 설명한다.

아래쪽 전기실 입구 앞의 작은 직원 전용 구획에 **수동 격리 셔터 한 개**만 추가한다. 왼쪽의 위험한 직원 통로 방화문과는 위치·번호·실루엣을 구분한다. ‘직원 전용’ 전체가 잘못된 경로인 것이 아니라, 같은 직원 구역에서도 설비 위험 통로와 E-01 전기실의 실제 목적지가 다르다는 기존 추리를 살린다. 새로운 방·NPC·조사 수집 목록을 늘리지 않는다.

```text
북쪽: 역 안내도 ─ 안내/매표 데스크 ─ 개찰구 안내문
서쪽: 위험 직원 통로 / 점검창       벤치·기둥       동쪽: 개찰구 → 계단
         │                    감염자 순찰              ↑
         └─ 서측 건조 우회로 ───── 상단 건조 가장자리 ──┘
중하단: 침수된 중앙 지름길 / 이후 잠기는 동측 짧은 연결로
남쪽: 시작·봉쇄문 ─ 직원 구획의 수동 셔터 ─ E-01 전기실(별도 안전 구역)
```

도식은 관계도이며 실제 좌표 확정 도면은 아니다. 기존 벤치를 낮은 은폐물로 바꾸지 않는다. 높은 기둥·안내 시설의 차폐와 비상등 아래 바닥 경계를 함께 읽게 한다.

## 핵심 행동은 두 개

### 1. 침수된 지름길을 보고 건조 동선으로 우회한다

- 시작: 대합실 진입 시 중하단 중앙 통로의 물 경계·기둥 수위 눈금·넘어진 통행 차단봉이 보인다. 짧은 자막으로 ‘중앙 통로 침수 / 서측 건조 동선’을 알린다. 시점을 강제로 돌리지는 않는다.
- 조작: 기존 이동과 시점만 사용한다. 중앙으로 밀고 들어가면 물 경계 앞에서 충돌로 멈추며 ‘이 구간은 깊어 진입할 수 없다’고 표시한다. 서쪽 건조 가장자리로 돌아 상단 안내 시설에 접근한다. 타이밍 점프·정밀 발판·번호 입력은 없다.
- 성공: 실제로 건조 경로를 걸어 조사 구역과 전기실 접근점을 연결한다. 이동 성공은 위치·통행 조건으로 판정한다.
- 잘못된 접근/복구: 물에 닿아 즉사하거나 반복 자원이 깎이지 않는다. 경계를 따라 돌아갈 수 있고 뒤로 물러나는 길도 유지한다. 감염자에게 붙잡힌 경우만 기존 체크포인트 재시도를 사용한다.
- 감염자와의 관계: 우회 중 상단 순찰을 보고 기둥 뒤에서 시야를 끊는다. 감염자는 물을 건너거나 벽을 통과하지 않는다. 적 증원 대신 기존 한 명과 통행 가능한 길의 관계가 변한다.

### 2. 직원 구획의 수동 셔터를 직접 열어 전기실 접근을 확보한다

- 시작: 안내 데스크 열쇠와 ‘E-01 / 직원 설비 / 격리 셔터 수동 조작’ 표식을 확인한다. 열쇠는 기존 전기실 문에 쓰며 추가 아이템을 요구하지 않는다.
- 조작: 가까이 조준해 E/상호작용으로 ‘고정 빗장 해제’ → 다음 입력으로 ‘셔터 손잡이 올리기’를 실행한다. 물리 장치에 빗장·열림 높이·고정 걸쇠가 실제로 바뀐다. 두 번의 의미 있는 조작이며 숫자/암호 선택은 아니다. 키를 누르고 있는 동안 반복 진행하지 않는다.
- 성공: 걸쇠에 고정된 셔터가 열린 상태로 유지되고 실제 충돌이 바뀐다. E-01의 기존 열쇠 문을 통해 전기실로 들어간다. 조작 중 카메라는 움직이지 않는다.
- 중단/실패/복구: 첫 조작 후 떠나거나 메뉴를 열면 다음 단계에서 이어 한다. 짧은 장치 동작 중 이동하면 해당 미완료 동작만 취소하고 재시도한다. 닫힌 셔터를 강제로 뚫거나 눌려 죽는 판정은 없다. 적에게 붙잡혀도 확정된 빗장/걸쇠 상태는 보존한다.
- 난이도: 첫 동작에서 충분히 떨어진 순찰과 시야 차단 위치를 보장한다. 반응속도 QTE나 양손 정밀 조작을 요구하지 않는다. 장치 조작 안내를 여는 경우 기존 규칙대로 위협을 정지하며, 실제 현장 조작은 안내를 닫고 시작한다.

## 플레이 순서

1. 봉쇄문 때문에 돌아갈 수 없다는 기존 도입 후, 침수 경계와 역의 통행 표식을 눈으로 읽는다.
2. **이동/우회:** 서측 건조 가장자리를 통해 상단 공용 공간으로 이동한다. 감염자 순찰을 보고 기둥 뒤에서 기다리거나 돌아간다.
3. **조사/추리:** 안내도와 점검창, 개찰구 안내문을 확인한다. 발견한 사실로 기존 질문을 선택한다. 긴 읽기는 정지형 기록창을 사용한다.
4. **조사:** 안내 데스크에서 기존 열쇠를 얻는다. 위험한 직원 통로를 선택했다면 기존 회피 사건 후 복귀한다.
5. **현장 조작:** E-01 앞 수동 셔터를 열고 직원 설비 공간으로 진입한다.
6. **안전한 판단/퍼즐:** 전기실에서 기록을 읽고 기존 두 회로 전원 분배를 한다. 방송 기록을 먼저 듣고 전원 조합을 바꿀 수 있다.
7. **공간 변화 관찰:** 전기실 복귀 문 앞에서 배관의 누수 증가와 수위 눈금 변화를 확인한다. 동측 지름길은 잠겼지만 서측/상단 건조 경로는 남아 있다.
8. **회피/이동:** 개찰구 소리에 반응한 감염자의 마지막 조사 위치를 읽고, 실제로 비어 있는 건조 경로로 이동한다. 짧은 시간제한은 넣지 않는다.
9. **통과:** 조명+개찰구 조건을 충족해 계단으로 이동하고 기존 발소리 연출·챕터 3 진입으로 이어진다.

조사만 연속하는 대신 이동 → 관찰/기다림 → 읽기/질문 → 물리 조작 → 안전한 전원 판단 → 바뀐 길을 통한 회피가 번갈아 나온다. 지도상 번호를 더 많이 암기하는 변화가 아니라 실제로 접근할 수 있는 길과 장치의 충돌이 바뀐다.

## 침수 단계와 감염자 동선

| 단계      | 전환 기준                                    | 통행 변화                                                  | 감염자                                                                     |
| --------- | -------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------- |
| 초기      | 챕터 진입                                    | 중하단 중앙 지름길 차단, 서측/상단과 짧은 동측 연결 유지   | 기존 상단·중앙 순찰 한 명                                                  |
| 누수 증가 | 전기실 첫 방문 뒤 복귀 시, 한 번만 현장 연출 | 동측 짧은 연결도 차단. 서측과 상단 건조 동선은 끝까지 유지 | 변경된 충돌을 기준으로 현재 위치에서 재탐색. 플레이어 좌표는 알려주지 않음 |
| 탈출 준비 | 개찰구 전원 최초 연결                        | 물은 더 오르지 않음. 출구는 조명+전원 조건 유지            | 개찰구 위치의 작동음을 한 번 조사한 뒤 기존 수색·복귀                      |

수위는 단계 기반이며 벽시계·접속하지 않은 시간으로 상승하지 않는다. 누수 증가의 원인은 현장 배관 파손으로 보여 주되 재난 전체의 기원이나 인물의 책임을 새로 확정하지 않는다. 배수펌프가 원래 작동 중이었다는 새 사실도 임의로 추가하지 않는다.

초기 후보 침수 영역은 벤치 아래 중하단 띠, 적 순찰은 그 위 건조 구역으로 분리한다. 단계 전환은 플레이어가 전기실 안에 있고 NPC·감염자가 새 차단 영역 밖에 있는 안전한 경계에서만 확정한다. 조건을 만족하지 않으면 장면 전환까지 전환을 보류한다. 화면 안의 인물을 순간이동시키거나 물 속에 가두지 않는다. 정확한 좌표는 플레이어 반지름·최저 이동 배율을 반영한 접근성 테스트 후 확정한다.

감염자 속도는 기존 편안한 이동 배율과 함께 바뀐다. 감지·추격·수색·복귀 상태를 새로 만들지 않고 `getWorld`와 같은 침수/셔터 충돌을 주입한다. 감염자가 출입구를 영구 점유하지 않도록 조사 후 복귀 경로를 검사한다. 전기실·메뉴에서는 기존 정지 규칙을 유지하므로 전기실 안에서 기다린 시간으로 바깥 수색이 끝난다고 안내하지 않는다. 복귀 뒤 차폐 위치에서 활성 탐색으로 동선을 확인하게 한다.

## NPC·저장·후속 챕터 영향

- 오반장은 기존 안내 데스크 근처 건조 구역에 둔다. 안내 경고는 관찰 가능한 누수·표식에 한정하며 다른 인물의 숨겨진 역할을 바꾸지 않는다. 챕터 3 생존자를 앞당겨 배치하지 않는다.
- 직원 통로 복귀 지점과 체크포인트는 모든 수위에서 충돌 없이 나오도록 검증한다. 직원 통로 사건/대화 중 적은 멈추며 복귀 전 안전 배치를 기존 전환 규칙으로 처리한다.
- 향후 저장 필드는 침수 단계와 셔터의 확정 상태, 누수 연출 완료 여부 정도로 제한한다. 물 파티클·적 경로·타이머·카메라 애니메이션은 저장하지 않는다. 조작 중 저장은 마지막 확정 단계에서 재개한다.
- 과거 저장은 기본적으로 초기 수위와 셔터 상태를 적용한다. 단 이미 전기실 방문/개찰구 전원 복구를 마친 회차에는 그 진행을 기준으로 셔터를 열린 상태로 호환하고 불필요한 재수집을 요구하지 않는다. 새 침수 안의 저장 위치는 전환 안내 후 기존 안전 체크포인트로 옮긴다.
- 챕터 3 이후 저장·엔딩 스냅샷은 변경하지 않는다. 챕터 2 완료 조건과 계단/생존자 도입은 유지한다. 어느 단계에서도 모든 필수 조사와 전기실·출구로 가는 접근성이 남아야 한다.
- 공개 증거 문구를 수정하게 되면 `chapter2Public.ts`와 서버 공개 증거 사본/계약 테스트를 함께 맞춘다. 비공개 인물 정책·정답은 변경하지 않으며 AI 호출은 기본 비활성이다.

## 어둠·에셋·범위

전체 노출을 일괄 낮추지 않는다. 비상등은 건조한 서측/상단 바닥 경계와 셔터 걸쇠를, 차가운 설비등은 위험한 설비/침수 경계를 구분한다. 개찰구 표식·기둥 모서리·적 실루엣은 정전 상태에서도 읽힌다. 물 경계에는 색 외에 사선 차단봉·수위 눈금·노면 글자를 사용한다. 소리는 기존 믹서/자막을 따르고 깜빡임·카메라 흔들림·강제 시점 회전을 추가하지 않는다.

현재 밝기 설정은 없으므로 다음 구현에서 화면·조작 설정에 제한된 밝기 슬라이더와 어두운 장면 확인용 샘플을 제안한다. 진행 판정이나 조명 회로 조건은 바꾸지 않으며 화면을 밝게 했다고 미점등 상태의 개찰구를 통과할 수는 없다. 값은 감도/FOV와 같은 별도 설정 저장에 둔다. 모바일 실기기에서 검은색 뭉개짐과 햇빛 아래 식별성을 비교해야 한다.

기존에 `public/art/README.md`로 관리하는 로컬 Kenney CC0 소품을 재사용한다. 역 시설 간판·수위 눈금·단순 셔터/레버·물 평면은 프로젝트 제작 메시와 텍스처로 구성할 수 있다. 실시간 유체·수면 반사 렌더 타깃·새 고해상도 모델·외부 다운로드를 필수로 하지 않는다. 신규 외부 에셋은 아직 선정/다운로드하지 않았으며 추후 선정 시 제작자·라이선스·수정 여부를 기록한다.

## 향후 구현·검증 순서

1. 기존 크기의 맵에 침수/셔터 상태별 `getWorld` 충돌과 건조 경로를 먼저 정의한다. 모든 필수 대상·NPC·체크포인트의 접근성을 조합별 자동 검사한다.
2. 수동 조작 두 단계와 영구 걸쇠, 취소·중복 입력·저장 복구를 구현한다. 클릭·E·터치를 같은 판정에 연결한다.
3. 수위 단계 연출과 감염자 경로 재탐색을 연결한다. 벽/물 너머 감지·관통·순간이동·출입구 봉쇄를 검사한다.
4. 조명·표식·음소거 자막과 선택적 밝기 설정을 적용하고 PC/모바일에서 조사→우회→조작→회피 순서를 플레이한다.
5. 최저 이동 배율·낮은 자원·직원 통로 성공/실패·열쇠 획득 순서 변경·누수 직전/직후/셔터 중간/완료 저장을 확인한다. 과거 저장과 챕터 3~6·엔딩, 외부 API 0회 회귀를 수행한다.

제안 당시에는 통행 폭과 체감 난이도를 검증하기 전이었고, 흐름·공간·수위·밝기·셔터는 **미구현**이었다. 이후의 확정 구현과 검증 결과는 위 구현 기록으로 분리한다.
