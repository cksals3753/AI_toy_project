# 중단된 새 게임 연속 검사

이 폴더의 01-first/02-hall 캡처·progress/checkpoints는 새 게임에서 실제 입력으로 시작한 검사 도중의 기록이다. 대합실 이후 자동 조준/셔터 입력 처리에서 중단됐으므로 챕터 1–6 완주 증거로 사용하지 않는다. 상태 주입 없이 시작했지만 엔딩까지 완료한 실행은 이번 작업의 통과 목록에 포함하지 않는다.

최종 회귀의 챕터별 진행·분기는 [상위 검증 기록](../README.md)과 [체크포인트 분기 결과](../branches/results.json)를 따른다. 기존 통합 검증 기록을 덮어쓰지 않도록 이번 작업의 산출물을 분리했다.

후속 최종 검증은 별도 새 게임에서 무주입 3D 연속 완주를 통과했다. [완주 결과와 실제 경로](../continuous-final/README.md)를 참고한다. 이 폴더의 중단 기록 자체를 완주 기록으로 바꾸지는 않는다.
