# 챕터 6 제작자 설정 — 에피소드 1 완결

제작·서사 검토용 문서이며 게임 UI에서 읽지 않는다. 기존 재난 및 인물 설정은 [챕터 5 제작자 설정](chapter5-author.md)을 유지한다. 새 조력자·적·전투·추종 AI·다음 에피소드는 추가하지 않는다.

## 고정된 현장 사실과 공개 순서

D-02 이동 승인을 완료한 플레이어가 별도 진입 동작으로 정비 분기실에 들어간다. 현행 대피도는 S-01의 지상 대피소 정문 연결과 G-01의 지하 등록 확인 구역 연결을 보여준다. 설명판에는 S-01/현장 수동 승인, G-01/외부 자동 승인, 두 경로 모두 지역 전원 유지 조건을 적는다. G-01 점검창에는 진입 뒤 차단문 폐쇄와 내부 해치가 보인다.

필수 판단 근거는 챕터 6의 대피도·설명판에서 전부 얻는다. 점검창과 과거 기록은 추가 반증이다. 이전 단서를 소급 획득시키거나 하지 않은 질문의 답변을 생성하지 않는다. 제어반의 설정 검증과 최종 이동 확정은 별도이며, 확인창에는 이미 발견한 근거만 표시한다. 설정 오류는 무비용 재시도 가능하다.

S-01은 대피소 정문으로 직접 연결된다. G-01은 실제로 별도 확인 구역에 진입해 차단되며, 내부 복구 안내와 배수 상태 조사 → 밸브 → 빗장 → S-02 해치 조작을 마쳐야 지상으로 나간다. 내부 복구는 체력·배터리·과거 소지품을 요구하지 않고 자원을 차감하지 않는다. 두 경로 모두 대피소 내부 표식을 조사하고 도착 확인대를 사용해야 완료된다.

## 인물과 공개 제한

서윤은 전달받은 근거에 대해 조건을 확인하도록 돕는다. 강태오는 자동 확인 경로를 권한 뒤 사용자가 반증을 공유하면 말을 바꾼다. 민재는 과거 기억의 한계를 인정하며 오반장은 지역 전원에 관한 실무적 답변을 한다. 각 질문은 해당 조사 이후에만 가능하다. 새로운 인물 신원 증거를 추가하지 않았으므로 수동 제출자·최종 정보 이용자·변조 배후는 공개하지 않는다. 이전 대피자들의 현재 안전도 결론 내리지 않는다.

## 동행과 완료 기록

동행 여부는 기존 chapter3.npcBoarded를 이어받으며 현재 구역을 보고 새로 추정하지 않는다. helped/invited 도움 기록은 진입·결과 대사에 반영한다. 동행자는 자동 경로에서도 구역 내부에 남아 있다가 해치 이동 시 함께 올라온다. 버리고 가는 선택은 없다. 비동행자는 신도림 비상 부스 옆 의자가 마지막 확인 위치이며 이후 구조 여부는 미확인이다.

도착 확인대 동작 한 번으로 자원·소지품·획득 단서 전문·실제 대화·질문·주요 선택·동행 상태·확인/미확인 사실을 결과 스냅샷에 복사한다. 결과 연출과 재열람은 상태 판정이 아니다. 읽음 상태 갱신이나 대피소 내 재조작으로 결과를 다시 생성하지 않는다. 인물 정답표, 점수, 등급, 보상은 없다.
