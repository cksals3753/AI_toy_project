# 챕터 3 · 누군가 있는 승강장 / 3D

승강장·열차 A 조사 객실·출발 직후 열차 B 객실을 공통 1인칭 탐색기로 표시합니다. 현재는 [챕터 4도 공통 열차 장면으로 확장](../chapter4-3d/README.md)해 3D를 유지합니다. 아래 챕터 4의 2D 전환 캡처·검증은 이전 작업 당시의 보관 기록입니다. 기존 이야기·질문·도움/초대/대기 분기·운행 승인과 신호·탑승 판정은 reducer에서 유지합니다. 추가 전투나 외부 AI 연동은 없습니다.

## 플레이 확인 순서

1. 챕터 2를 완료하고 계단에서 E로 승강장에 진입합니다. 기둥 뒤 생존자를 조사하고 도움 또는 방향 안내를 선택합니다.
2. A-17 / △-1의 열린 문을 조사하고 확인창에서 객실에 들어갑니다. 잠긴 선두의 운행 중지 표식을 확인한 뒤 출입문에서 승강장으로 돌아옵니다.
3. B-04 / ◇-2, 비상 부스의 오늘 운행 기록, 안전 난간의 선로 표식을 조사합니다. 휴대폰의 기존 선택형 추가 질문과 단서 노트를 사용할 수 있습니다.
4. 승인 장치에서 잘못된 차량·선로를 제출해도 자원 소모 없이 수정할 수 있습니다. 현장 기록에 맞춰 승인하면 신호가 전환됩니다.
5. 외부 비상 호출로 B의 문을 엽니다. 문이 닫힌 동안 충돌이 남고 개방 후 문턱을 통과할 수 있습니다. 차량 몸체·안전 난간·기둥은 통과할 수 없습니다.
6. 생존자에게 도움을 줬으면 동행합니다. 방향만 안내했다면 다시 찾아 탑승을 초대하거나 구조 대기를 확인합니다. NPC가 답을 대신 고르지 않습니다.
7. B 선두의 출발 확인창에서 명시적으로 최종 탑승합니다. 탈출 대화를 마치고 챕터 4 시작을 선택하면 같은 중앙 객실의 3D 탐색과 동행 상태로 이어집니다.

## 저장·입력·에셋

- `view3d`에 구역·x/z·yaw/pitch를 저장합니다. 현재 NPC 위치와 문 상태를 포함한 `world.ts` 충돌로 복원 위치를 검증합니다. 벽·차량·NPC와 겹치는 카메라 값은 버립니다.
- 기존 2D 저장은 진행·단서·체력·배터리·분기를 유지하고 현재 구역의 안전 시작점에서 시작합니다. 2D x/y를 3D x/z로 사용하지 않습니다.
- E·Tab·I·Esc, 대화/퍼즐 일시정지, 명시적 마우스 잠금 복귀, 모바일 터치, 로딩 제한·재시도·2D 복귀, 자원과 이벤트 정리는 기존 공통 컴포넌트를 재사용합니다.
- 생존자는 기존 Kenney CC0 리깅 모델과 갈색 의복의 별도 파생 스킨을 사용합니다. 머리와 발목의 붕대 표식은 기존 초상화와 연결합니다. 오반장과 별개의 인물입니다. 출처는 [에셋 기록](../../public/art/README.md)에 있습니다.
- 사운드는 추가하지 않았습니다. 기존 발소리·기침·출발 사건은 자막과 대화로 유지합니다. NPC는 기존 도움/초대 대화 중 한 모델을 짧게 페이드해 고정 위치를 변경하며 추종 AI는 없습니다.

## 검증 실행

```sh
npm run build
npm run lint
npm test
FIRST_PERSON_CHECK=chapter3 npm run test:browser:first
```

브라우저 검사는 챕터 2 완료 체크포인트에서 실제 E 이동으로 진입합니다. 도움·방향 안내·추후 초대·단독 탑승, 열차 A 조사/복귀, 승인 오답/수정, 신호·개방, 저장 재접속과 과거 위치 복구, 챕터 4 전환, 모바일 터치/메뉴를 검사합니다. 전체 챕터 회귀는 별도의 기존 2D 경로 검사입니다. 외부 AI는 비활성이며 브라우저 검사에서 `/api/chat` 요청 0건을 확인합니다.

## 수행 결과

- TypeScript/Vite 빌드, ESLint, Prettier 형식 검사 통과. 빌드의 3D 청크 크기 경고는 남습니다.
- 단위·계약 테스트 14개 파일, 122개 테스트 통과. 현재 NPC 위치·B 문턱·차량 몸체·저장 카메라 검증과 챕터 4 렌더러 경계를 포함합니다.
- 챕터 3 3D Chrome 플레이: 계단 진입, 필수 조사, NPC 도움/방향 안내/초대/대기, A 왕복, 승인 오답/수정, B 개방, 동행/단독 출발, 저장 복원과 과거 2D 안전 위치 복구, 챕터 4의 기존 2D 전환 통과.
- PC E·Tab·I·Esc, 메뉴 중 이동 차단, 모바일 390×844 조이스틱·메뉴 복귀·전체 화면 높이 확인. 모바일은 실제 기기가 아닌 터치 에뮬레이션입니다.
- 기존 2D 경로의 챕터 1~6 통합 회귀 통과. 동행/단독, 챕터 5 두 응답 분기, 챕터 6 두 경로, 저장/복원과 일회성 사건을 확인했습니다.
- 브라우저 런타임 오류 0건, 외부 AI `/api/chat` 요청 0건. 실제 모델 호출 검증을 수행하지 않았습니다.
