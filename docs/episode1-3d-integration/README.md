# 에피소드 1 전체 3D 통합 검증

2026-10-17, 로컬 Vite + 헤드리스 Chrome(CDP, SwiftShader)에서 검증했습니다. 자동화가 실제 키보드·마우스·터치를 전달합니다. 사람이 직접 조작한 플레이 시간이나 실기기 성능 측정으로 해석하지 않습니다.

## 새 게임 연속 경로

`FIRST_PERSON_CHECK=episode npm run test:browser:first`

브라우저의 새 프로필에서 새 게임을 시작합니다. 이 경로에는 localStorage 쓰기, 완료 플래그 주입, reducer 직접 호출, 위치 워프가 없습니다. 탐색기는 월드 데이터를 읽어 경로를 계획하고 실제 WASD 이동·마우스 조준·물리 E키로 조사합니다. 선택·퍼즐 입력은 기존 UI를 사용합니다. 저장 복원은 앱이 만든 현재 저장을 수정하지 않고 새로고침·이어하기로 확인합니다.

경로:

1. 첫 방 안내도·패널·물품함·오반장 조사, 단톡방 질문, 서쪽 정비문 탈출.
2. 대합실 단서와 열쇠 획득, 직원 통로 위험 사건, 전기실에서 개찰구·조명 전원 복구.
3. 계단에서 승강장 진입, 생존자를 부축, 열차 A 내부 조사·복귀, B-04 승인·신호·문 개방·최종 탑승.
4. 중앙·후방·선두 조사, 외부 송신 연결 분리, 신호 동기화, 문래역 정차·하차 승인.
5. 표시 이름 확인, 경고와 신발·방송 조사, 무응답, 안내 부스 등록 대조·보류, 현장 정비문 대조·이동 승인.
6. S-01 수동 경로, 별도 이동 확정, 대피소 내부 표식, 명시적 도착 확인과 에피소드 결과.

최종 수정 코드의 연속 실행은 첫 탐색부터 엔딩 확정까지 195초, 새로고침·결과 재열람까지 198초(3분 18초)였습니다. 대사 넘김과 정답 입력이 자동화되어 있으므로 일반 사용자의 플레이 시간은 아닙니다. 도착 기록은 체력 80, 배터리 51%, 단서 30개, 생존자 동행, 수동 경로였습니다.

체력·배터리·열쇠·단서·NPC 기록은 해당 회차에서 실제 획득한 값입니다. 결과 스냅샷의 자원·소지품·단서·단톡방 기록을 도착 당시 게임 상태와 대조합니다. 챕터 경계와 등록 처리 뒤 새로고침, 엔딩 저장·결과 재열람도 검사합니다. [최종 소요 시간·상태](result.json), [구역별 측정](progress.json), [수정 없는 실제 체크포인트](checkpoints.json), [콘솔·에셋·AI 요청 기록](network.json)을 별도로 남깁니다.

## 발견 및 수정

반복 이동 시 화면의 Canvas는 1개였지만, 폐기된 렌더러의 Canvas가 힙에 남았습니다. 힙 스냅샷에서 Three r186의 공유 `DFG_LUT` 텍스처 → dispose 리스너 → 이전 WebGL 컨텍스트·Canvas의 참조 경로를 확인했습니다.

`rendererResources.ts`가 공개 `onBeforeCompile` 훅으로 실제 컴파일된 보정 텍스처를 추적하고, 공통 탐색 렌더러 종료 전에 해제합니다. 기존 재질 훅도 보존·복원합니다. 이 처리는 현재 앱의 단일 탐색 렌더러 수명에 맞춘 것으로, Three 업그레이드나 다중 렌더러 도입 시 재검증해야 합니다. 스토리·정답·진행 조건은 변경하지 않았습니다.

동일 대합실↔전기실 8회 왕복, 각 시점 강제 GC 뒤 측정:

| 지표                                  | 수정 전      | 수정 후      |
| ------------------------------------- | ------------ | ------------ |
| DOM 노드                              | 378 → 826    | 378 유지     |
| 전체 JS 이벤트 리스너                 | 173 → 189    | 173 유지     |
| window 키다운/키업/마우스/blur 리스너 | 2/2/1/2 유지 | 2/2/1/2 유지 |
| 화면 Canvas                           | 1 유지       | 1 유지       |

[수정 전 원자료](stability-before.json), [수정 후 원자료](stability.json). 수정 후에도 JS 힙은 약 19.1 → 20.9 MB로 증가했습니다. 코드·캐시 워밍업과 자동화 평가 코드의 영향을 모두 분리한 측정은 아니므로, DOM·리스너 잔류가 해소됐다는 결과를 전체 메모리 누수 0이나 GPU 메모리 안정성 보장으로 확대하지 않습니다. 짧은 반복 검사이며 장시간·실기기 VRAM은 미검증입니다.

PC Tab·I·Esc에서 메뉴 중 이동 차단과 복귀, 이동키를 누른 채 실제 브라우저 탭 이탈·복귀 후 입력 초기화를 확인합니다. 모바일은 두 터치를 동시에 보내 조이스틱 이동과 오른쪽 시점 회전, 두 터치 해제 후 정지를 확인합니다.

초기 검증 도구가 챕터 2 완료창, 통신 단절 시 패널 자동 종료, 엔딩 이어하기의 결과창 자동 표시를 누락해 멈춘 건은 테스트 순서를 수정했습니다. 이들은 게임 진행 오류로 집계하지 않습니다.
