# 챕터 5–6·에피소드 결과 사운드

첫 방에서 확인한 35% 기본값과 기존 WebAudio 합성·설정 저장·재생 허용 구조를 재사용합니다. 녹음된 철도 음원이나 TTS가 아닙니다. 음성·새 음악 시스템·외부 서비스·게임 사건·저장 필드는 추가하지 않았습니다.

## 상태별 재생

| 구간        | 실제 상태와 소리                                                                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 열차→문래역 | 같은 컨텍스트에서 승강장 설비 음색으로 전환. 정차한 열차 주행은 재개하지 않음                                                                            |
| 문래역      | 낮은 환풍·전기 설비음과 실제 이동 발걸음                                                                                                                 |
| 방송        | 새 스크립트 장면 시작 시 앞으로 나올 방송의 짧은 차임. 이름 낭독 없음. 기록·자막 재조사에는 없음                                                         |

| 정비 통로   | 배관·환풍 느낌의 필터 노이즈. 설정이 실제 바뀌면 스위치음, 선택 문이 바뀌어 열릴 때 문 소리, 자동 경로 이동 확정 시 차단문·경고                          |

| 완료·결과   | 내부 표식 조사 후 도착 확인이 성공할 때만 짧은 완료음. 탐색 버스·발걸음을 종료하고 완료음 뒤 컨텍스트 일시정지. 결과 재열람·완료 저장 로드는 완료음 없음 |

기존 판정값을 비교하는 `chapter56Audio.ts`는 게임을 변경하지 않습니다. 로드한 상태를 기준으로 시작해 이전 사건을 재생하지 않습니다. 물소리는 객실 설비·주행 소스와 분리되며 배수·구역 이탈·완료에서 종료합니다. 메뉴·대화·퍼즐 중에는 기존 탐색 입력 및 실제 이동 기반 발걸음이 중지됩니다. 탭 이탈·음소거·음량 저장·재생 불가 시 무음 진행을 유지합니다. 완료음은 이전의 문 개방·장치음을 대신해 새로운 판정을 만들지 않습니다.

## 경로별 직접 확인 순서

1. 문래역 하차 후 표시 이름을 확인합니다. 새 방송 전 짧은 차임과 기존 자막을 확인하고, 방송 기록을 다시 조사해 차임이 반복되지 않는지 확인합니다.
2. **응답:** 경고·감지기 조사→명시적으로 대답→감지·차단문→활성 등록과 안내 확인→취소·해제→승강장 복귀→안내 부스 대조·외부 유도 보류.
3. **무응답:** 경고·감지기 조사→응답하지 않음→안내 부스 기록 대조·등록 보류. 차단문 사건음은 없어야 합니다.
4. 두 분기 모두 정비 통로 표식을 확인하고 실제 개방→이동 승인을 거쳐 챕터 6에 들어갑니다.
5. **수동:** 현행 지도·설비 조사→S-01/local/전원 설정·문 개방→별도 이동 확정→대피소. 통로 소음이 완만하게 낮아지는지 확인합니다.
6. **자동:** G-01/remote/전원 설정→별도 이동 확정→차단 사건→내부 안내·수위 조사→밸브·배수 완료→빗장·해치→대피소. 배수 완료 뒤 물소리가 남지 않아야 합니다.
7. 대피소 내부 표식 조사→도착 확인. 완료음 뒤 결과 화면에서 탐색음이 멈추는지 확인합니다. 결과 닫기·재열람·새로고침에서도 완료음이 반복되지 않아야 합니다.
8. 각 분기의 동행·비동행, 배수 전후 및 완료 저장, 음소거·볼륨 변경·탭 전환·모바일 터치를 확인합니다.

## 남은 확인

실제 iOS/Android·Safari, 기기 스피커·헤드폰·블루투스 출력과 청감 균형은 미검증입니다. 자동 피크 검사는 실행한 기본 음량·해당 조작 시퀀스의 결과이며 모든 기기·최대 음량에서의 청각적 편안함을 보장하지 않습니다. 합성음은 게임 분위기용이고 실제 철도·배수 시설 조작 소리의 재현이 아닙니다. 필수 정보는 기존 자막·상태·시각 안내로 모두 확인할 수 있습니다.

정비 문은 기존 월드 판정상 설정 대조 시 열리므로 해당 시점에 개방음을 연결했습니다. 수동 이동 확정 때는 이미 열린 문 소리를 반복하지 않고, 자동 이동 확정 때는 뒤쪽 차단문 소리를 냅니다. 같은 종류의 효과음은 최소 250ms 및 해당 소리 길이 동안 중복 생성을 막습니다.
