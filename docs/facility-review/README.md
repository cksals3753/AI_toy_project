# 챕터 2 시설 식별·조사 거리·간판 개선

2026-10-25. 챕터 2 재구성 이후의 추가 피드백을 반영했다. 이 문서는 챕터 2 개선 당시의 기록이며, 이후 챕터 1·3–6에 적용한 개별 거리·형상과 검증은 [후속 에피소드 시설 점검](../episode-facilities/README.md)을 따른다. 기존 작업 트리의 침수·감염자·셔터 단계·단서·회로·저장 구조를 기반으로 수정했다. 새 수집 대상·진행 단계·퍼즐 정답·외부 에셋·API 호출은 추가하지 않았다.

## 원인과 수정

큰 시설 표식은 두 줄 문장을 768×384 텍스처에 넣고 넓은 양면 평면으로 표시했다. 특히 IS-02 앞 차폐판의 E-01 간판은 눈높이에 돌출돼 가까이 지나가면 화면을 덮었다. 해당 표식을 차폐판 위로 올리고 짧은 시설 번호로 줄였다. 벽면 안내와 문패도 폭·높이를 줄이고 실제 읽는 방향의 단면만 렌더링한다. 북측 간판은 벽 가까이, 남측 문패는 출입구 위에 두며, 눈높이 통로에 큰 평면을 놓지 않는다. FOV·카메라 위치·시점·이동 속도를 강제 변경하지 않는다.

얇은 안내도·안내문은 실제 프레임 두께에 맞춰 기존 바닥 충돌을 줄였다. 배전반도 폭 180→90 월드 단위로 줄여 모바일에서 세 회로가 한눈에 보이게 했다. 새 충돌체를 추가해 길을 좁히지 않는다. 저장 위치를 막는 새로운 영역은 없으며 기존 위치 검증·안전 복원은 그대로 사용한다.

긴 설명·전압 경고·회로 조건·단서 전문은 기존 조사 대화/단서 노트에 남아 있다. 작은 시설 라벨은 줄 수에 맞는 텍스처 높이와 큰 글꼴로 작성해, 평면 크기를 키우지 않고 읽을 수 있게 했다. 선택 보조 바닥 테두리는 선택 시에만 작고 낮은 불투명도로 표시한다.

## 용도별 외형

- **안내도:** 북측 벽의 얇은 프레임, 구역 도식·분기선·현재 위치. 바닥부터 솟은 불투명 박스를 제거했다.
- **통로 점검창:** 그릴·배관·전압 계기·바늘·작은 설비 표시등을 구분한다. 파란 표시등이 안전한 길을 뜻하는 것으로 바꾸지 않았다.
- **안내 데스크:** 다리와 상판, 열린 서랍, 손잡이와 열쇠 고리를 표현한다. 기존 데스크 조사로 열쇠를 얻으면 열쇠 형상만 사라지며 저장 후에도 중복 표시하지 않는다.
- **예비 전원 배전반:** 세 회로의 모듈·표시부·스위치를 분리한다. 기존 조명/개찰구/방송 전원 상태에 따라 해당 스위치 기울기가 바뀐다. 조사 UI와 최대 두 회로 조건은 그대로다.
- **IS-02:** 레일·수평 빗장·손잡이·상단 걸쇠가 다른 부품으로 보인다. 개방 시 손잡이도 셔터와 함께 올라가며 떠 있는 임시 형상을 남기지 않는다.
- **개찰구 안내:** 거대한 시설 박스 대신 얇은 안내판과 지지대로 표현한다. 별도 새 조사 ID는 없다.

보이지 않는 조사 판정체와 이동 충돌은 분리돼 있으며, 조사 판정체 재질을 화면에 렌더링하지 않는다. 장식에는 조사 ID를 추가하지 않았다. 기존 저폴리 재질과 자체 Three.js 기본 형상을 사용한다.

## 대표 거리와 판정

월드 단위이며 괄호는 해당 구역의 `sceneScale`로 나눈 게임 렌더러 거리다. 실제 철도 시설의 치수나 실제 사람의 작업 거리 규격이 아니다. 경계값 미만에서 활성화한다.

| 대상                       | 이전      | 변경        | 판정 표면                                     |
| -------------------------- | --------- | ----------- | --------------------------------------------- |
| 역 안내도                  | 60 (1.50) | 125 (3.13)  | 벽 프레임 앞면 y=84–86, x=440–520             |
| 통로 점검창                | 60 (1.50) | 100 (2.50)  | 그릴/계기 앞면 y=157–160                      |
| 개찰구 안내문              | 60 (1.50) | 110 (2.75)  | 얇은 판 앞면 y=187–190                        |
| 데스크·열쇠 보관           | 60 (1.50) | 85 (2.13)   | 상판·서랍이 있는 데스크 외곽, 남측 앞면 y=163 |
| 전원 배전반                | 60 (1.20) | 135 (2.70)  | 회로·스위치 앞면 y=181–185                    |
| 셔터                       | 60 (1.50) | 75 (1.88)   | 빗장/손잡이가 있는 앞쪽 y=425–430             |
| 첫 방·챕터 3–6의 기타 대상 | 60        | **60 유지** | 기존 개별 판정체                              |

`interaction.ts`에 용도별 거리와 표면을 모았다. 3D는 보조 광선이 실제로 맞힌 표면점까지의 수평 거리를 사용한다. 2D는 동일 표면 사각형의 가장 가까운 점까지 거리를 계산하며 같은 거리 정책을 따른다. 셔터 현장 조작/완료 reducer도 같은 표면·거리 함수를 사용한다. E·마우스 클릭·모바일 버튼은 탐색기가 선택한 한 대상을 같은 핸들러로 실행한다.

기존 공통 판정의 문제도 확인했다. 큰 모델의 피벗이 화면 밖에 있으면 표면에 조준해도 우선순위가 나빠질 수 있어 광선의 충돌점으로 점수를 계산한다. 중앙 조준점 주변의 기존 제한된 보조 광선은 유지하고 선택 유지 여유를 보정했다. 작은 두 대상의 경계에서 미세한 시점 변화로 깜빡이지 않으며, 벽·닫힌 문·먼 거리에 가려지면 유지 선택도 즉시 버린다. 작은 전경 조작부가 큰 후경 판정체에 선택을 빼앗기지 않는 검사도 추가했다. 단, 다른 물체에 실제로 완전히 가려진 대상은 선택하지 않는다.

## 검증 범위

- 자동 검사: 24개 파일, 221개 테스트. 기존 챕터 1–6·저장·결과 검사와 새 거리/표면, 큰 대상의 가장자리·사선·거리 밖·벽, 밀집한 작은 대상과 선택 유지 검사.
- 타입·린트·정적 플레이테스트 빌드: 통과. Three.js 지연 청크 약 763 kB 경고는 유지하며 임계값을 바꾸지 않았다.
- 실제 Chrome 프로덕션 시각/조작: **통과**. 고정 시점 전후 캡처, 편안한 거리에서 안내도·점검창·데스크·배전반 조사, 사선 조준, 거리 밖 비활성, 차폐벽과 닫힌 셔터 뒤 대상 차단, 간판 옆 이동, 어두운 상태의 밝기 양끝, 첫 방 패널, 모바일 배전반 터치→기존 UI→복귀를 확인했다. 실행 결과는 [시각·거리 검사](after-result.json)와 [요청/콘솔 검사](production-network.json)를 따른다.
- 실제 진행 회귀: 침수 우회·감염자 회피·두 단계 셔터·중단/저장/재시도·회로 변경/방송 기록·누수 증가·챕터 3 연결, 직원 통로 양쪽 결과와 모바일 동시 조작도 통과했다. 대합실 진입 체크포인트부터 이동 배율 0.6·체력 1·배터리 0·음소거로 진행했으며, 최종 통과 실행의 붙잡힘 재시도는 0회였다. [진행 결과](progression-result.json)와 [분기·조작 결과](progression-controls.json)를 별도 기록한다. 첫 방부터 엔딩까지 새로 전수 진행한 검사는 아니다.

## 검사 중 보완

실시간 위협을 무시한 기존 자동 경로는 데스크 접근 중 반복해서 붙잡혀 종료됐다. 게임의 감염자 속도/판정을 낮추지 않았다. 경로 계산에 새 표면과 편안한 접근 거리를 적용하고 조사 순서를 조정했다. 테스트가 매 회전마다 오래 대기하거나 500px 이상의 OS 포인터 급변 방지값을 넘기던 합성 마우스 입력도, 정상 한계 안의 빠른 연속 입력으로 보완했다. 실패한 자동 실행을 통과로 집계하지 않으며 최종 정상 완료 결과만 위 JSON에 남겼다.

## 미검증·제약

실제 iOS/Android, 실제 GPU/디스플레이의 암부 식별성·체감 조작감은 미검증이다. 모바일은 Chrome 터치 에뮬레이션이며 실기기 검사로 보고하지 않는다. 다른 챕터의 시설 외형을 일괄 변경하지 않았고 모든 후반 대상을 브라우저에서 다시 전수 조사하지도 않았다. 공통 선택 계산은 단위 검사와 첫 방 패널로 보완하며, 후반 기본 거리는 유지한다. 저장·사건·엔딩 구조에는 새 필드를 추가하지 않았다.

가까이 붙으면 시설물 자체가 화면을 채울 수는 있지만, 간판이 통로 눈높이에서 카메라를 가로지르는 문제와 구분한다. 시설 라벨의 상세 내용은 휴대폰 비율에 따라 작게 보일 수 있어 HUD 이름과 기존 조사 기록 UI를 함께 사용한다. 데스크는 서랍을 내려다봐야 조준된다. 새 마이크·외부 네트워크·서버·수집 단계는 없다.
