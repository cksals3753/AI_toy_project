# 챕터 2 침수·현장 셔터 재구성

후속 [시설 식별·조사 거리 개선](../facility-review/README.md)이 현행 간판·거리·외형을 설명한다. 아래는 최초 재구성 검증 기록이며, 같은 경로의 캡처/자동 결과는 후속 재검증에서 갱신될 수 있다.

2026-10-25. [승인 전 제안서](../chapter2-restructure-proposal.md)의 공간·침수·셔터가 미구현인 코드에서 시작했다. 새 맵·적·전투·상시 시간제한은 추가하지 않았다. 기존 960×600 대합실, 감염자 한 명, 열쇠·사실·선택형 질문·방송·최대 두 회로·직원 통로 결과·챕터 3 연결을 유지한다. 공개 증거의 내용과 계약은 바꾸지 않았으므로 서버 측 사본도 변경하지 않았다. 비공개 인물 역할·정답은 그대로다.

## 변경된 플레이

1. 첫 방에서 대합실에 진입한다. 중앙 침수 경계 때문에 직선으로 가로지르지 못한다. 서측으로 우회하며 기존 점검창·안내도·개찰구 안내·데스크를 조사한다. 조사 대상이나 필수 수집 수는 늘리지 않았다.
2. 감염자를 관찰하고 기둥·IS-02 앞 차폐판으로 시야를 끊는다. 전기실 앞 직원 설비 구획으로 이동한다. 서쪽 위험 직원 통로의 방화문과 남쪽 **IS-02 수동 격리 셔터**는 별개다.
3. 셔터에 조준하고 E/클릭/모바일 조사 버튼을 한 번 누른다. 약 0.9초 후 빗장이 해제된다. 다음 한 번의 입력으로 셔터 올림·걸쇠 고정을 완료한다. 길게 누르거나 연타할 필요가 없다. 진행·취소·확정 단계를 HUD에 표시한다.
4. 설명창은 위협을 정지한다. 닫고 하는 현장 조작에서는 위협이 움직인다. 이동·메뉴·포커스 이탈·붙잡힘은 미확정 조작을 취소하며 확정된 빗장은 유지한다. 완료된 셔터는 다시 조작하지 않는다.
5. 열쇠로 E-01에 들어가 기존 예비 전원을 판단한다. 방송 기록은 기존처럼 방송 회로에서 확보하고, 탈출에는 조명·개찰구 회로가 필요하다. 전기실은 기존 안전 구역이다.
6. 첫 전기실 방문 이후, 플레이어와 감염자가 새 침수 범위 밖인 활성 탐색 프레임에만 누수가 확정된다. 적이 해당 위치에 남아 있으면 전기실 안에서도 보류하며 대합실 복귀 후 다시 검사한다. 실제 프로덕션 플레이에서도 이 보류가 발생했다. 전원 순서나 왕복으로 수위가 되돌아가지 않는다.
7. 늘어난 동측 침수를 피해 서측·상단 건조 경로로 개찰구에 접근한다. 기존 완료 기록·계단·챕터 3 진입을 진행한다.

이전에는 조사→전원→개찰구가 중심이었다. 이제 같은 정보를 얻는 동안 물 경계를 읽고 건조 우회로를 고르며, 감염자를 피해 차폐판 뒤에서 현장 조작한 다음 달라진 동선으로 돌아온다. 물에 닿아 즉사하거나 체력을 반복 차감하지 않는다.

## 확정된 통행 구조

좌표는 기존 2D 월드 기준이며 3D도 같은 판정을 변환해 사용한다. 초기 중앙 물: `(390,320)–(610,420)`. 추가 동측 물: `(690,330)–(910,470)`. 수면·경계띠·차단봉은 이 사각형과 일치한다. 플레이어와 감염자 반경 13에 대한 충돌 여유는 별도로 적용된다. 물은 이동 장애물이고 시야 차단 벽으로 처리하지 않는다.

IS-02는 `(144,430), 106×12`, 양옆 구획 벽은 x=130/250이다. 앞 차폐판은 `(180,300), 80×22`이며 시야를 끊는다. E-01 문의 중심은 x=200이다. 중앙 물의 서측과 상단, 서쪽 직원 통로 복귀점, 전기실 출입구의 접근 영역을 유지한다. NPC 고정 위치는 추가 침수 밖이다. 감염자는 전기실 출입으로 재배치되지 않고 정지한 런타임에서 재개하며, 수색 후 이동하므로 출입구를 영구 점유하지 않는다.

| 단계      | 차단             | 유지                                         |
| --------- | ---------------- | -------------------------------------------- |
| 초기      | 중앙 지름길      | 서측·상단 우회, 동측 짧은 연결               |
| 누수 증가 | 중앙 + 동측 연결 | 서측·상단 우회, 전기실·직원 통로·개찰구 접근 |

## 화면·저장

비상등·경계띠·시설 표식으로 위험 영역과 건조 우회를 구분한다. 공용 공간→직원 설비→승강장 표식을 유지하고 조작 설명은 HUD/도움말에서 제공한다. 밝기는 85–125%, 기본 100%이며 도움말에 확인 샘플이 있다. 기존 감도·FOV·이동 배율과 같은 별도 설정 저장을 사용하고 충돌·전원 판정을 바꾸지 않는다. 기존 음소거·자막은 유지한다.

새 영구 상태는 `chapter2.water`, `visited`, `leakShown`, `shutter`다. 진행률·적 좌표·동작 타이머를 저장하지 않는다. 중간 조작 저장은 마지막 확정 단계로 복원한다. 과거 전기실/전원/완료/후반 저장은 셔터가 열려 있던 것으로 호환한다. 침수·벽 안의 저장 위치는 안내 후 안전 위치로 옮기고 잘못된 3D 시점을 폐기한다. 챕터 3~6 상태와 결과 스냅샷은 기존 것을 유지한다.

## 검증 중 보완한 불일치

- 조준은 셔터 가장자리를 선택했지만 조작이 임의 중심점 거리 때문에 취소되던 문제를 실제 판정 사각형 기준으로 통일했다.
- 같은 조사 ID의 빗장/개방 라벨이 HUD에서 갱신되지 않던 문제를 수정했다.
- 전기실 왕복에서 적 런타임이 재생성되면 누수 안전 확인과 실제 적 위치가 어긋날 수 있어 같은 런타임을 정지·재개하도록 했다. HUD의 경계 상태도 그 런타임에서 복원한다.
- 초기 충돌 시안의 좁은 구획 때문에 추가 침수 후 우회 경로가 끊기는 경우를 경로 검사에서 찾아, 구현 좌표를 확정하기 전에 중앙 물과 셔터 구획 폭을 조정했다.
- 기존 챕터 2 브라우저 스크립트는 경계 중 저장을 불러온 후 안전 복귀 안내를 넘기지 않고 마우스 잠금을 요구해 중단됐다. 저장 안전 규칙을 완화하지 않고 테스트가 실제 안내를 닫도록 보완했다.

## 제약과 남은 불편

실제 휴대폰·GPU·디스플레이의 암부 식별성과 인간 플레이어의 체감 난이도·멀미·청감은 미검증이다. 헤드리스 Chrome의 모바일 에뮬레이션을 실기기 검사로 보지 않는다. 출입구를 적이 점유한 모든 배치와 셔터 조작 중 실제 붙잡힘은 전수 브라우저 검사를 하지 않았으며, 취소/확정 보존은 상태·동작 커널 검사로 보완했다. 모든 수위·문 상태의 실제 회피를 전수 플레이한 것도 아니다.

가까운 시설 간판이 시야를 크게 차지하고, 상단 우회에서 적을 피하려면 기다리거나 메뉴로 확인해야 하는 불편은 남는다. 물은 고정 단계의 얕은 사각 수면이며 유체 시뮬레이션이 아니다. 셔터 완료는 확정 순간에 형상이 바뀌는 간단한 연출이다. Three.js 공통 3D 청크 약 761 kB 경고가 남으며 임계값 상향이나 무관한 구조 변경은 하지 않았다.
