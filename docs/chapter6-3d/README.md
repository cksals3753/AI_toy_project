# 챕터 6 — 정비 통로 3D 검증

분기실·자동 경로 복구 구역·지상 대피소를 공통 1인칭 탐색기로 표현합니다. 기존 상태와 퍼즐 판정, 동행 기록, 에피소드 결과 스냅샷을 유지합니다. 새 챕터나 외부 에셋은 추가하지 않았습니다. 기존 생존자 모델과 시설 재질을 재사용합니다.

## 플레이 확인 순서

- 수동: 챕터 5 정비문 이동 승인 → 대피도·설비 설명판·기록 확인 → 제어반에서 S-01 현장 수동 경로 설정 → 이동 별도 확정 → 대피소 정문 → 내부 표식 조사 → 도착 확인 → 에피소드 결과.
- 자동: G-01 자동 확인 경로 설정 → 이동 별도 확정 → 차단된 복구 구역 → 내부 해제 안내·배수 상태 조사 → 밸브 → 빗장 → S-02 해치 → 대피소 측면 → 내부 표식 조사 → 도착 확인 → 에피소드 결과.

오답·순서 오류는 기존 안내와 재시도로 처리합니다. 대피소 입장만으로 완료되지 않습니다. NPC는 동행 상태에 따라 한 명만 배치하며 복구 작업을 대신하지 않습니다. 배수 전후 수면, 문·해치·빗장 표시와 충돌은 기존 게임 상태에서 결정합니다.

## 저장과 검사

기존 2D 저장은 진행·분기·자원을 보존하고 구역별 안전 위치로 복구합니다. 새 저장은 위치와 시점을 검증해 복원합니다. 닫힌 문·가구·NPC와 겹친 위치는 안전 위치로 복구합니다. 자동 경로 대피소 진입은 측면, 수동 경로는 정문 위치를 사용합니다.

- `npm test`: 14개 파일, 136개 테스트 통과. 실제 저장 로드, 문·해치 충돌, 동행 위치, 분기별 도착 위치 검사를 포함합니다.
- `npm run lint`: 통과.
- `npm run build`: TypeScript 검사와 프로덕션 빌드 통과.
- 브라우저 검사의 최종 결과와 미검증 항목은 아래 기록을 참고합니다.

빌드의 500 kB 경고는 지연 로드되는 공통 3D 청크(753.01 kB, gzip 199.67 kB)에서 발생합니다. 해당 청크는 Three.js, 모델 로더와 각 구역의 장면 팩토리를 함께 포함합니다. 경고 임계값은 변경하지 않았습니다.

## 제약

PC Chromium과 모바일 화면·터치 에뮬레이션을 사용합니다. 실제 휴대폰, Safari, 다양한 GPU 및 장시간 메모리 안정성은 미검증입니다. 사다리·해치는 기존 구역 전환이며 등반·수영 물리나 NPC 추종 AI는 없습니다. 결과는 기존 2D React UI입니다. 외부 AI는 비활성 상태로 검증합니다.
